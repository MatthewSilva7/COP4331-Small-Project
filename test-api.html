API Tests: Register & Search Contacts

Run from the same origin as your app (e.g. http://localhost:8080/smallproj/test-api.html).

Test cases

Register API

  1. Register success – valid data, unique login → 200, id > 0, no error.
  2. Register missing fields – empty firstName (or lastName/login/password) → 200, error "Missing required fields".
  3. Register duplicate login – login that already exists (e.g. "RickL") → 200, error "Login already exists".

Search Contacts API

  1. Search full – userId: 1, search: "" → 200, contacts array (all for that user).
  2. Search part (name) – userId: 1, search: "Alice" → 200, at least one contact with firstName "Alice".
  3. Search user ID required – userId: 0 or missing → 200, error "User ID required".
  4. Search no matches – userId: 1, search: "ZZZNoMatch" → 200, contacts empty array.
  5. Search filter by phone – userId: 1, search: "123-456" → 200, at least one contact (e.g. Alice).
  6. Search filter by email – userId: 1, search: "alice@" → 200, at least one contact.
